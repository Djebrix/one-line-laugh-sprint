One original funny line on everyday life (max 200 characters) for make.fun's
One-Line Laugh Sprint. The program writes the line to `/output/entry.txt`;
an AI judge ranks the lines pairwise on how funny, fresh and tightly worded
they are.

Entry: "I asked my smart speaker for the weather and it told me to look
outside — turns out it's been taking sarcasm lessons from me."

Run it with Python 3.13 (standard library only, no network, deterministic):

```sh
python3 main.py
```
